    # Dataset Reference

## Overview

The original dataset used in this project was privately provided and is not publicly available for redistribution. Therefore, the original dataset files are not included in this repository.

For reference, a publicly available dataset covering a similar domain and prediction task is provided below. It contains ride-related information from Uber and Lyft, making it a useful alternative for understanding the dataset structure and the overall project concept.

## Reference Dataset

**[Uber & Lyft Cab Prices – Kaggle](https://www.kaggle.com/datasets/ravi72munde/uber-lyft-cab-prices/data)**

The reference dataset contains ride pricing information from Uber and Lyft, including features related to:

- Ride timestamps and dates.
- Pickup and destination locations.
- Cab service providers.
- Ride categories and vehicle types.
- Pricing information.
- Weather-related conditions.

## Download Instructions

1. Visit the Kaggle dataset page using the link above.
2. Sign in to your Kaggle account.
3. Navigate to the **Data** section.
4. Click **Download** to download the dataset.
5. Extract the downloaded files.
6. Place the required dataset files inside this directory if you want to explore the reference data.

## Important Notes

- This Kaggle dataset is provided for reference purposes only.
- It is not the actual dataset used in this project.
- The original project dataset was privately accessed and cannot be publicly redistributed.
- The reference dataset provides a similar data domain and structure but may differ in its features, records, and distribution.
- Using this reference dataset will not necessarily reproduce the original project results.
